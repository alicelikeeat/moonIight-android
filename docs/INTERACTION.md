# 月光 — 交互语言 (v5.0)

点按和长按是两种不同的逻辑：**点按做事，长按给选择**。圆环只放最常用的，其余全部收进 ··· 面板。

## 原则

| 手势 | 含义 | 例子 |
|---|---|---|
| **点按** | 这个东西**唯一、最明显的主要操作**，永远不是菜单 | 视频：播放/暂停 · 图片：显示/隐藏控件 · 缩略图 / 封面 / 朋友圈媒体：打开播放 · 头像：打开主页 · 标签：切换 |
| **双击** | 喜欢（首页）/ 赞（朋友圈） | 双击不会取消赞 |
| **长按** | 上下文圆环，**最多 4 个**这个对象最常用的操作 + 中心 **···** | ··· 打开毛玻璃底部面板，按 播放 / 分享与保存 / 整理 / 危险 分组列出全部其他操作 |
| **上下滑** | 下一条 / 上一条 | |
| **左滑** | 首页内容的详情卡（来源、大小、日期、标签） | |
| **双指** | 视频：铺满 / 完整显示；图片：缩放 | 只影响这一条 |
| **右边缘** | 返回（系统手势） | |
| **长按标签** | 整个页面的选项（不放在单条内容的圆环上） | 首页：筛选 全部/本地/在线 · 随机一条 · 重新洗牌 · 回到顶部 |
| **计数 1/22** | 点按 = 跳转 / 拖动定位；长按 = 首页圆环 | |

**删除永远不在圆环上**，只在 ··· 面板最下方单独的「危险」分组里（并带撤销）。这条规则由 `MenuSpec.ring()` / `sheetGroups()` 统一执行，所有圆环自动遵守。

## 圆环

| 场景 | 圆环（≤ 4） | ··· 面板 |
|---|---|---|
| 首页视频 | 收藏 · 倍速 · 声音 · 分享·保存（次级弧：分享 · 保存到相册 · **下载** · 发到朋友圈） | 播放（暂停、循环、静音、画面、信息）· 分享与保存 · 整理（隐藏）· 危险（删除） |
| 首页图片 | 收藏 · 停留时间 · 设为背景 · 分享·保存（同上，含 **下载**） | 同上 |
| 在线 / 嵌入 | 收藏 · 在浏览器打开 · 下一个同源 · 分享 | 同上 |
| 播放页（同一对象 = 同样的手势） | 收藏 · 声音 · 分享·保存（含 **下载**）· 随机/换源 | 播放 · 分享与保存 · 整理（隐藏、关闭播放器） |
| 朋友圈视频 (v5.0) | **没有长按圆环**：点按 = 原地 播放/暂停（PlayToggle）· 长按 = 直接进入全屏播放页。开启「定时长按」时，长按的进入改在松手时，按住到时间则弹出 播放/暂停 · 进入播放页面 · 声音 · 保存（次级弧 保存到相册 · **下载**） | — |
| 朋友圈动态 | 赞 · 踩 · 评论 · 转发到聊天 | 编辑 · 复制 · **自动播放**（有视频时）· 改发布者 · 危险（删除 → 最近删除） |
| 好友 | 聊天 · 主页 · 以 TA 发动态 · 编辑 | 替 TA 聊天 · 自动回复 · 危险（删除） |
| 聊天消息 | 复制 · 回复 · 改发言人 · 撤回 | 危险（删除） |
| ● 拍摄 | 拍照 · 录像 · 导入 · 发朋友圈 | — |
| 库缩略图 | 收藏 · 发朋友圈 · 分享·保存 · 多选 | 播放 · 分享与保存 · 整理 · 危险（删除） |
| 首页标签 / 计数 / 空白 | 筛选 · 随机一条 · 重新洗牌 · 回到顶部 | 随机顺序 · 声音 |
| 其他标签 | 2–4 个页面级入口 | — |

带子选项的按钮（倍速、停留时间、分享·保存、筛选、改发言人、转发到聊天）**在圆环外侧展开一小段次级弧**，不替换圆环；子选项超过 6 个时改为列表。

### 视觉

- 4 个按钮分布在约 110° 的弧上，背向最近的屏幕边缘；半径 118dp，56dp 玻璃按钮，按钮间约 18dp 空隙。
- 标签是按钮外侧的小字说明，有足够间距；中心是 ··· 小按钮（没有其他操作时为小圆点）。
- 遵守 设置 › 外观 › **菜单背景**（透明 / 轻度模糊 / 模糊）和 **长按菜单选择方式**（点击：长按打开，松手保持，再点选；拖动：按住滑到按钮松手即选）。
- **长按动画**（v4.2）：旋转 / 荷花 / 星轨 / 月光 / 随机（在启用的样式中随机）。
  - 旋转：按钮沿弧线旋转弹出（不变）。
  - 荷花：圆环从手指处绽开，每个按钮先是一个闭合的花苞，内层 5 瓣、外层 8 瓣半透明玻璃花瓣依次展开，露出中间的按钮；收起时花瓣合拢成花苞并下沉淡出。约 520ms + 38ms 错峰。
  - 星轨（v4.2，取代坠落）：像片头的星星绕山飞入——玻璃按钮本身（带图标）从远处、屏幕上方出发，一个接一个沿着绕手指的弧线飞来（约 210° 的弧），透视上由极小持续长大（0.12 → 1.06），落入圆环位置后回弹到 1，身后留下渐细的暖光轨迹和闪烁的光点，落定时一圈柔光 + 轻触反馈；收起时按钮缩小、沿弧线飞回远处。约 500ms + 45ms 错峰，收起约 300ms。
  - 月光：整屏（含状态栏下方、内容、标签栏）暗到约 95% 黑，右上方升起月亮，月光束依次照亮每个按钮（银白发光圆盘 + 光晕 + 发光标签）；收起时光先暗下、屏幕再恢复。此样式忽略「菜单背景」。
  - 系统「动画时长缩放」为 0 时所有样式只淡入淡出。
  - 静止状态不依赖动画是否播完：每个时钟结束 / 被取消时都直接定格到 1，另有按动画缩放计算的看门狗；按钮的缩放 / 透明度以普通值传入 graphicsLayer，绝不在延迟执行的 lambda 里读共享数组（v4.1 坠落按钮停在很小的原因）。选中的操作在点按时立即执行（0ms），收起动画（约 300ms）不延迟它。
  - 旧版本保存的值自动迁移：模糊→清晰 / 坠落 → 星轨，破碎→完整 → 荷花，月光表盘 → 月光。
  - 性能：花瓣、光晕、光束、彗尾都在单位坐标里预先建好 Path / Brush，每帧只做变换；整层一个 Canvas。

## 底部面板

毛玻璃，分组行（图标 + 标题 + 副标题），「危险」分组单独放在最后并标红，下滑关闭，返回键关闭。

## 一致性

同一个对象在任何地方手势一样：首页、播放页、朋友圈、库、主页。
- 视频：点按播放/暂停（首页）或打开（缩略图），长按圆环；
- 封面 / 头像：点按全屏播放，长按 = 更换 · 调整位置 · 播放 · 恢复默认；
- 缩略图：点按打开，长按圆环 + ···。

## 视觉基调

8pt 网格（8 / 16 / 24 间距），统一的字号层级（标题 titleMedium、正文 bodyLarge/Medium、说明 labelMedium），outlined 图标 22dp（子选项 20dp），动效统一用 spring（打开 ~0.6 阻尼回弹，关闭临界阻尼）。

## 菜单配色规则 (v4.3)

只有在媒体之上（首页信息流、全屏播放器）打开的圆环 / ··· 面板 / 二级弧 / 底部面板才用 MediaGlass 深色玻璃；其它地方一律跟随 LocalMoonColors（浅色主题 = 浅玻璃 + 深色文字）。

- `tabMenu(i, …, onFeed)`：所有标签（含首页）`forceDark = onFeed`；从 我 / 朋友圈 长按 首页 标签不再是灰白描边。
- `homeRing(…, overMedia)`：信息流上为 true；空信息流且背景为主题时为 false。
- `feedMenuSpec`（单条内容）与 `PlayerChrome` 始终在媒体上 → 深色。
- `SheetSpec.dark`：··· 面板继承 `spec.forceDark`；信息卡 / 跳转面板在信息流上 → 深色。面板内容通过 `LocalMoonColors` 取色，标签与图标颜色与圆环一致。
- 动画不变。

## 按键背景 (v4.3)

设置 › 长按圆环 › 按键背景。每个按键可以独立跟随主题、用一张图片或一段视频。

- **背景（skin）**：`SkinDef(id, kind, path, focus, scrim, owner)`。在某个按键的编辑页里新选的媒体 = 该按键专属背景；批量选择时可选「共用同一个」或「各自选择」（逐个按键选）。
- **绘制**：所有按键走同一条路径 `skinOr / skinFill`（`ui/design/ButtonSkin.kt`）：按焦点 / 缩放裁切、遮罩强度（0.10 + 0.56·强度）、按亮度自动选图标颜色（亮图 → 白遮罩 + 深色图标）。
- **视频**：静音循环；每个视频背景一个播放器（多个按键共用），最多同时播放 4 个，其余显示封面，空出位置后再播放；播放器池化，`ON_STOP` 暂停、不可见 / 不再使用即释放。
- **回退**：文件缺失或无法解码 → 跟随主题；没有背景的按键保持「媒体上深色 / 其它跟随主题」的默认。
- **删除**：重置按键或删除一个背景从不删除其它背景的文件；未被引用的文件只在用户确认后，或点「清理未使用」时删除。
- **持久化**：DataStore `button_skins`（JSON）；解码时丢弃未知 / 已移除的按键 id 和悬空背景。

## 下载 (v4.4)

分成两种，互不混用：

| | 主动下载 | 自动缓存 |
|---|---|---|
| 触发 | 长按 › 分享·保存 › **下载**（首页、播放页、朋友圈视频）；··· 面板「分享与保存」里也有「下载到「我的下载」」 | 浏览时自动（Coil 缩略图/图片缓存在 cacheDir/coil，播放器内存缓冲） |
| 存放 | 进行中：filesDir/downloads/*.part；完成：filesDir/media/dl_*.* | cacheDir（系统可随时清理） |
| 出现在 | 库 › **我的下载**（进行中 + 已完成），首页 › 本地 | 不进库，不进「我的下载」 |
| 进程被杀 / 重启 | 保留：WorkManager 唯一任务 `dl:<条目 id>`，启动时 KEEP 重新入队；HTTP Range 断点续传 | 丢了就丢了，不续传 |

- 圆环上限 4 个不变：下载放在「分享·保存」的次级弧里（不新增圆环按钮）。
- **只有提供文件直链的来源**可以下载：Archive、NASA、Commons、PeerTube（实例给出的文件地址）、Pexels、Pixabay、粘贴的直链、网页来源里找到的图片/视频文件、朋友圈附件已上传的文件。哔哩哔哩、YouTube、Vimeo、Dailymotion、Twitch 只有网页播放器，HLS/DASH（.m3u8 / .mpd）属于流媒体：不提供下载（圆环上不出现；··· 面板里显示为灰色并写明原因）。不解析 playurl / WBI，不绕过 DRM。
- 任务：前台通知显示进度；暂停 = 停止任务并保留 .part；继续 = `Range: bytes=N-` + `If-Range`（ETag / Last-Modified）；服务器不支持 Range（返回 200）或文件已变化 → 清空 .part 从头下载；416 且已完整 → 完成；408 / 429 / 5xx / 断线 → 指数退避重试（最多 6 次）后标记失败，可在库里「重试」；完成后校验大小与文件头（必须是图片/视频）。
- 库 › 我的下载：正在下载（进度、暂停/继续、取消、失败重试）+ 已下载网格；筛选标签显示进行中数量。从库里删除已下载项后再次下载会重新开始。

## 数据写入 (v4.4)

social.json：调用方只替换内存状态；编码与写入都在 IO 线程，250ms 去抖、只写最新状态，tmp + fsync + 原子 rename；离开应用（onStop）时立即写出待写内容。下载任务表 downloads.json 用同一个写入器。


## 朋友圈视频自动播放 (v5.0)

- 视频在动态的媒体框里**原地小窗**静音循环，朋友圈和个人主页（包括从 消息 打开的主页）都一样。
- 设置 › 朋友圈自动播放：**全部同时播放**（看得见的都播，最多 6 个，超出的显示首帧）· **只播指定的**（⋯ 里标了「自动播放」的动态 + 设置里选中的好友）· **关闭**。另有「仅 Wi‑Fi」。
- 优先级：你点开播放的 → 你暂停的（保留画面，不会被自动播放重新开始）→ 自动播放的（按可见比例）。
- 播放器池复用 `VideoBudget`（上限 6，闲置池 2 个）；滑出屏幕立即释放，App 退到后台全部暂停，回来按计划继续。
- v4 的静态 ▶ 原因：唯一的共享播放器由 `LaunchedEffect(target, byId)` 绑定，没有以播放器为 key。设置流先发出默认值再发出保存值，`rememberMomentPlayback(mode)` 因此重建了播放器，新播放器从未被绑定（`currentAtt` 一直为 null）；从 消息 打开的主页根本没有播放器；一次也只能播一个。

## 定时长按 · 全部按键 (v5.0)

第三层手势，纯状态机 `HoldMachine`（单元测试覆盖）：

| 层 | 何时 | 结果 |
|---|---|---|
| 点按 | 0.5 s 内松手 | 主要操作 |
| 长按 | 0.5 s | 圆环照常打开（时间不变） |
| 定时长按 | 继续按住到 5 / 10 / 自定义 3–15 s | 手指旁显示 “3.2s” + 光环倒计时；到时 该场景分配的按钮执行（震动 + 提示 + **撤销**）。未分配 / 关闭「到时自动触发」= 只弹出菜单 |
| 全部按键 | 在屏幕**中心圆**（短边 30%）按住 5 s | 圆环先照常打开，5 s 时过渡到毛玻璃「全部按键」：当前内容 · 页面 · 全局（录屏、设置、外观、拍摄、筛选、最近删除…）。倒计时为**月相** |

- 分配按场景：首页内容 / 底部标签 / 朋友圈视频 / 播放页。**危险操作（删除…）不在可分配列表里**，自动触发前再检查一次 `destructive`，永远不会被自动执行。
- 冲突规则：一次手势只有一个目标——从中心圆开始的按压只会走向「全部按键」，不会触发定时执行；中心之外走定时。手指移动超过 slop（18dp）取消两层计时（拖动选择照常）。
- 朋友圈视频：开启定时长按时，长按进入播放页改为松手时进入，按住到时间则弹出视频圆环。
- 设置 › 定时长按：总开关（默认关）· 触发时间 · 显示计时 · 倒计时动画 · 到时自动触发 · 各场景分配 · 全部按键（独立开关，默认开）。

## 录屏 (v5.0)

- 入口：底部标签 ··· · 内容 ··· · 播放页 ··· · 全部按键 › 全局（圆环仍然 ≤ 4）。
- 系统授权对话框 → 前台服务（mediaProjection 类型，通知带「停止」）→ MP4。只录画面 / 画面 + 麦克风用 MediaRecorder；录应用声音（Android 10+ AudioPlaybackCapture）时用 MediaCodec + MediaMuxer，麦克风混入。
- 顶部 ⏹ + 计时胶囊（可拖动），点按停止；保存到 库（可选同时保存到相册）。
- 拒绝授权 / 拒绝录音权限：提示并只录画面（或不录），不会卡住。受保护（DRM / FLAG_SECURE）内容可能是黑屏——**不绕过**。

## 星轨 (v5.0)

按钮从屏幕上方的天空出发，很小、旋转着，沿螺旋弧绕手指加速落下、逐渐长大，落地时略冲过头再回位，并有光圈爆开 + 火花，最后一道光沿按钮边缘扫过。分层星光拖尾（冷色光晕 · 暖色光带 · 白色内芯）+ 运动残影，划过整片天空的流星，远近不同的按钮大小/透明度不同（视差）。关闭时反向旋转飞回天上。设置 › 星轨速度：慢 / 标准 / 快 + 0.5–2× 细调，试一试实时预览。看门狗保留，结束时永远是满尺寸。

## 删除 · 碎纸机 · 最近删除 (v5.0)

- 确认规则不变（仍是危险操作确认面板）。确认后内容进入 **库 › 最近删除**（默认保留 30 天，可选 7 / 90），播放 碎纸机：竖条（大块内容交叉切割）从缝里落下，视频在纸条里**继续播放**。
- 撤销 / 从最近删除恢复 = 倒放（纸条飞回、拼合、升起）。「同时从相册删除」是永久删除：仍有动画，但不进最近删除。
- 适用：库、首页（本地内容）、朋友圈动态。设置 › 删除动画：碎纸机 / 简单淡出 / 关。
